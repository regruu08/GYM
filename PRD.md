# IronForge website scope

Eight public pages: home, programs, coaches, memberships, fitness tools, contact, first-visit guide, and privacy information. Next.js 16, React 19, TypeScript and Tailwind CSS 4.

Design palette: #090C10 ink-black, #11161C dark surfaces, #DCE3E7 cool silver, #C6AF87 champagne, #E7D7B8 light champagne. Full-width hero photography, blurred translucent panels, and restrained hover and entrance animation.

The website is a client-review implementation. Business-specific content remains subject to client verification. It has no payment, authentication, reservation database or email-delivery backend. The contact flow explicitly prepares an email draft and does not imply a confirmed booking. Class availability is confirmed by the team.

Acceptance checks: production compilation, TypeScript and lint validation, security regressions, route availability, interactive navigation, program filtering, pricing toggle, enquiry review/edit, and invalid calculator input handling. See README.md for launch dependencies and security boundaries.
